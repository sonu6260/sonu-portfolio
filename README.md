# Sonu Ahirwar — Developer Portfolio

Responsive portfolio website made with HTML, CSS, and JavaScript.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or place the folder inside XAMPP's `htdocs`.
3. With XAMPP, visit `http://localhost/sonu-portfolio/`.

## Customize before publishing
- Replace `YOUR_EMAIL@example.com` in `assets/script.js` with your preferred public contact email.
- Review the About and Skills sections for accuracy.
- The Personal Expense Tracker is labeled as a concept/practice project; link it only after its code exists.
- Add a profile photo or resume link if you want.

## Files
- `index.html` — page content
- `assets/style.css` — responsive styles
- `assets/script.js` — mobile menu and email-copy interaction
